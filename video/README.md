# 🎬 Tutor Académico - Video Tutorial Programático (Remotion)

Este directorio contiene la composición de video profesional de 45 segundos en resolución Full HD (1920x1080 a 30 fps) estructurada con la metodología de razonamiento pedagógico de **Gemini Argon**.

---

## 🚀 Cómo Previsualizar o Renderizar el Video

### 1. Instalar dependencias:
```bash
cd video
npm install
```

### 2. Previsualizar interactivamente en el navegador:
```bash
npm start
```
Esto abrirá el reproductor de Remotion en `http://localhost:3000`, donde podrás pausar, revisar cada fotograma y ajustar estilos o textos.

### 3. Renderizar el archivo final en MP4:
```bash
npm run render
```
El archivo de video final se generará automáticamente en:
`video/out/video-tutorial.mp4`

---

## 📑 Estructura de las Escenas

1. **Escena 1 (0:00 - 0:09):** Introducción de impacto & presentación de Archie ("Sin Scroll Compulsivo").
2. **Escena 2 (0:09 - 0:19):** Demostración de Microlecturas & Checkpoints Cognitivos (+5 💎).
3. **Escena 3 (0:19 - 0:29):** Mapa Conceptual en Segundo Plano con timeout de 8.5s y analogías prácticas.
4. **Escena 4 (0:29 - 0:39):** Evaluación Oral por Voz y Reporte Psicopedagógico por Correo.
5. **Escena 5 (0:39 - 0:45):** Cierre, enlace y llamado a la acción.
